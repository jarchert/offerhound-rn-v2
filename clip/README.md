# App Clip — `com.emergentmindlab.offerhoundv2.Clip`

This directory is a stub placeholder for the OfferHound iOS **App Clip** entry
point. The actual Swift sources for the clip currently live at
`../ios-prebuild-assets/AppClip/` and are wired into the generated Xcode
project by `../plugins/with-app-clip.js` on `expo prebuild`.

This `clip/` directory exists so future iterations can host:

- A pure-Swift entry view (`AppClipApp.swift`, `AppClipEntryView.swift`) when
  we move sources out of `ios-prebuild-assets/`.
- A lightweight TypeScript bundle if/when we adopt an RN-based clip flow
  (currently **not** the chosen path — Apple's <10 MB budget is easier to hit
  with native SwiftUI).
- Asset catalogs scoped to the clip (`Assets.xcassets`).

## What an App Clip needs

| Requirement                         | Status / Where it lives                                             |
| ----------------------------------- | ------------------------------------------------------------------- |
| Explicit bundle ID                  | `com.emergentmindlab.offerhoundv2.Clip` — locked in plugin           |
| Apple Team ID                       | `8MG7GFDJ62` — in `with-app-clip.js`                                 |
| Parent app association              | Embedded into `OfferHound.app/AppClips/` by the plugin               |
| Associated domains                  | `applinks:offerhound.app`, `appclips:offerhound.app` (+ `www.`)      |
| Sport-path advanced experiences     | `/football`, `/basketball`, `/track-field`, `/soccer`, `/baseball`, `/lacrosse`, `/golf`, `/volleyball`, `/swimming`, `/softball`, `/hockey`, `/cheerleading`, `/wrestling` |
| Binary size                         | **< 10 MB uncompressed** — keep dependencies minimal (no Hermes JS)  |
| Entitlements                        | `OfferHoundClip.entitlements` (generated)                            |
| Info.plist                          | `Info.plist` (generated by plugin from `ios-prebuild-assets/AppClip/`)|
| App Clip card image                 | Configured in App Store Connect (1200×800 PNG)                       |
| Default URL                         | `https://offerhound.app/<sport>` invocation URLs (smart banner / NFC)|

## How to build

```bash
# From the app/ directory
npx expo prebuild --platform ios --clean
# Then:
cd ios && pod install && cd ..
npx eas build --profile preview --platform ios   # clip ships inside parent
```

The clip is **embedded** in the parent app binary — there is no separate EAS
build profile (Apple ships clip + parent together via TestFlight / App Store).
